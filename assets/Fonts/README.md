# IBM Plex Mono

Bundled Light, Regular, and Medium font files are from the Google Fonts source repository:
https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Copyright IBM Corp. Licensed under the SIL Open Font License 1.1; see IBM-Plex-OFL.txt.

Both app configurations register these fonts through UIAppFonts. Typography uses the PostScript names IBMPlexMono-Light, IBMPlexMono-Regular, and IBMPlexMono-Medium. No font request is made at runtime.
