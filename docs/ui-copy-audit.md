# Pyxis copy and feature clutter audit

Audit date: 2026-10-01. Current local editorial-archive checkout, `codex/editorial-archive`. Fresh captures from the native preview app on an iPhone 18 Pro simulator running iOS 27, dark appearance, default Large text.

Scope: screens surrounding the approved Closet and Fit builder. The approved main layouts were used for navigation, not reconsidered. This pass changed no app source.

The main offenders are Try On, Fit Passport, Add Piece, and the detail pages. Profile and the native search/filter patterns are already concise.

## First cuts

| Priority | Surface | Concrete change |
| --- | --- | --- |
| 1 | Try On | Remove the unavailable preparation flow from normal navigation. Remove the slogan and extra headings when the feature is available. |
| 1 | Fit Passport | Separate saved measurements from size-chart comparison. Say “All fields optional” once; move measuring tips behind a help action. |
| 1 | Add Piece | Remove database-style section headings and the second Notes label. Collapse optional metadata; use one cutout-failure message. |
| 2 | Item / Fit detail | Keep garment codes and names. Remove repeated processing status and zero wear counts; group occasional actions in menus. |
| 2 | Suggestions | Keep the outfits. Remove three repetitions of their origin, preset poetic names, and the prose describing visible colors. |
| 3 | Fits search | Use a date or thumbnail to distinguish unnamed fits instead of repeating “Untitled fit.” |

### 3. Fit passport / sizing — Overexplained

**Source-only finding:** CONFIDENCE percentage is generated by a hand-written range/count formula, not a calibrated probability. Result state not rendered.

### 5. Add Piece — Overlabelled

**Keep:** Photo sources use clear verbs. Debug-only Demo image is correctly excluded from release source.

### 8. Try On — Needs the most cutting

**Keep:** Photo quality instructions support getting a usable reference; garment selection has a visible six-piece limit.

**Cut or change:** YOUR CLOTHES. YOUR PERSPECTIVE. is a slogan. START WITH YOU adds another heading before the photo instructions and CHOOSE YOUR PHOTO. ## Source-only concerns

- **Sizing confidence looks more precise than its basis.** The displayed percentage comes from a handwritten formula using measurement count and range distance ([service line 65](/Users/isaiahjohnson/.codex/worktrees/editorial-archive/Pyxis/src/services/SizeRecommendationService.swift:65)). A clearer result would say which measurements match the chart. The result state was not rendered in this audit.
- **AI De-wrinkle was correctly hidden when unavailable.** Its separate photo-upload disclosure is present in source ([AddItemFlow line 170](/Users/isaiahjohnson/.codex/worktrees/editorial-archive/Pyxis/src/views/AddItem/AddItemFlow.swift:170)). Preserve its stated provider/retention terms when rewriting it; do not copy Try On’s different retention wording.
- **Unused legacy views are outside this audit.** Current navigation reaches the native screens captured above. Old component strings should not be treated as visible product copy merely because they remain in the repository.

## Copy rules for the cleanup

Keep garment codes, meaningful field labels, photo requirements, recovery actions, informed photo consent, and destructive confirmations. Remove labels that merely announce the page or describe data already visible. Prefer sentence case for instructions and errors; reserve all caps and monospaced type for short archive metadata. Keep accessible names even when a visible label becomes shorter.

Examples:

| Current copy | Suggested treatment |
| --- | --- |
| YOUR CLOTHES. YOUR PERSPECTIVE. | Remove |
| START WITH YOU | Your photo |
| WHAT WOULD YOU LIKE TO TRY? | Pieces |
| DISPLAY NAME | Name |
| IDENTITY / CLASSIFICATION / ORGANIZATION | Remove the generic section headings; keep field labels |
| NOTES + NOTES | One Notes label |
| ORIGINAL ONLY + BACKGROUND REMOVAL FAILED — RETRY | Couldn’t remove the background. You can save the original. |
| WORN 0 TIMES + LAST WORN NEVER | Hide empty history, or show Not worn yet once |
| MARK WORN TODAY / WORE TODAY | Wear today |
| Your draft is saved on this device | Remove from the routine resume row |
| PRIVATE BY DEFAULT + long measurements footer | Saved on this device. Not sent with AI photos. |

- **Not verified:** The truth of provider retention promises. The privacy findings concern wording and placement, not a legal or backend compliance audit.
